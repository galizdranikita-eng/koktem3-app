KOKTEM-3 — загрузка на GitHub Pages

1. В репозитории koktem3-app нажмите Add file → Upload files.
2. Распакуйте ZIP и перетащите ВСЕ 6 файлов в область загрузки:
   - index.html
   - manifest.webmanifest
   - service-worker.js
   - icon-192.png
   - icon-512.png
   - .nojekyll
3. Внизу нажмите Commit changes.
4. Откройте Settings → Pages.
5. В Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
   Нажмите Save.
6. Подождите 1–3 минуты.
7. Ссылка будет:
   https://galizdranikita-eng.github.io/koktem3-app/
